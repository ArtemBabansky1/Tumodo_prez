# Правила типографики и шрифтов

## Основной шрифт (решение пользователя, 2026-08-04)

- **Основной шрифт презентаций — Nunito Sans** (используется на обложке библиотеки и в подписях Figma).
- Inter встречается в брендбуке — роль уточняется; без отдельного решения в слайдах не использовать.
- Файлы шрифта (woff2/ttf) должны лежать в `files/` — на 2026-08-04 ещё не загружены, ждём от пользователя.

## Шкала для презентаций (стили Figma `Presentation/*`, файл «Библиотека», страница «Текст» 1:46)

Все 7 стилей — Nunito Sans. Прочитаны из локальных стилей файла 2026-08-04.

| Роль (токен) | Стиль Figma | Начертание | Размер | Интерлиньяж | Трекинг | Где применять |
|---|---|---|---|---|---|---|
| `cover-title-1` | Presentation/Заголовок Обложка (1) | ExtraBold (800) | 80px | 110% | +1% | Заголовок титульного слайда — основной вариант |
| `cover-title-2` | Presentation/Заголовок Обложка (2) | ExtraBold (800) | 60px | 110% | +1% | Заголовок обложки для длинных названий |
| `page-title` | Presentation/Заголовок Страница | Bold (700) | 50px | 110% | 0 | Заголовок любого внутреннего слайда |
| `body-big` | Presentation/Основной текст (big) | SemiBold (600) | 30px | 125% | 0 | Подзаголовки, ключевые тезисы, лид |
| `body-middle` | Presentation/Основной текст (middle) | Regular (400) | 25px | 125% | 0 | Базовый текст и буллеты |
| `body-small` | Presentation/Основной текст (small) | Regular (400) | 20px | 125% | 0 | Плотные списки, вторичная информация |
| `caption` | Presentation/Сноски, баблы, графики | Regular (400) | 16px | 115% | 0 | Сноски, подписи к графикам, тексты в баблах |

Правила:

- На слайдах используются **только** эти 7 ролей. Промежуточные размеры «на глаз» запрещены.
- Не более 3 разных размеров на одном слайде (заголовок + текст + подпись).
- Межабзацный отступ основного текста — 20px (`spacing.paragraph`).
- 16px — минимально допустимый размер текста на слайде.

## Шрифт для соцсетей (стили `SMM/*`) — НЕ для слайдов

`smm-cover-l` 100px Bold/110%, `smm-cover-s` 74px Bold/110% (трекинг −2%), `smm-title` 60px Bold/110%, `smm-body` 43px SemiBold/57,01px (абзац 20px), `smm-caption` 32px Regular/42px (трекинг +1%, абзац 15,03px). Применяются в форматах Instagram post/stories, в презентациях не использовать.

## Цвет текста

- Стиль Figma «Text» = **#2E2E2E** (= токен `neutral.dark-gray-text`) — основной текст на светлых фонах.
- Стиль «Text_web» = #3A3A3A — только веб; в палитре презентаций отсутствует, на слайдах не использовать.
- На тёмных и синих фонах — White #FFFFFF (по правилам палитры).

## Файлы шрифта

**`files/NunitoSans-Variable.woff2`** (210 КБ) — вариативный шрифт, загружен пользователем 2026-08-04. Один файл покрывает все нужные начертания: проверено в браузере, ось веса работает в диапазоне **200–1000** (метрика различается на каждом шаге: 400 → 600 → 700 → 800).

Подключение (для `templates/html/css/tokens.css`, этап 4):

```css
@font-face {
  font-family: 'Nunito Sans';
  src: url('fonts/NunitoSans-Variable.woff2') format('woff2');
  font-weight: 200 1000;   /* вариативная ось веса */
  font-style: normal;
  font-display: block;     /* block, а не swap: слайд не должен «прыгать» шрифтом */
}
```

Правила:

- Использовать только веса из шкалы: 400 (Regular), 600 (SemiBold), 700 (Bold), 800 (ExtraBold). Промежуточные значения оси (например 550) не применять.
- Курсивного файла нет — синтетический курсив (`font-style: italic`) на слайдах не использовать; выделение — весом.
- При сборке файл копируется в `output/<имя>/fonts/` (самодостаточная презентация).
