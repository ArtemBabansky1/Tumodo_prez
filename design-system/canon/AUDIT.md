## Главный вывод: реальная система макетов другая

Список из 9 макетов был придуман заранее, до эталонов. Настоящие слайды
показывают систему из ~4 семейств с общим каркасом.

**Сквозной каркас (есть почти на каждом слайде):**
эйрбоу-подпись колоды слева вверху (серый ~20px) · логотип справа вверху
(чёрный на светлом, белый на синем/тёмном) · номер слайда слева внизу (серый, мелкий) ·
синий H1 · белые карточки со скруглением ~32px и мягкой тенью · синие буллеты ·
три темы: светло-серая, синяя, тёмно-синяя.

**Семейства композиции:**

| Семейство | Каркас | Примеры |
|-----------|--------|---------|
| A. Титул | Синий фон с волнами, логотип вверху, заголовок внизу | `cover`, `final`/`statement` |
| B. Шапка + ряд карточек | Бейдж/иконка + H1 → строка «label + описание» → ряд карточек | `title-bullets` (3 колонки), `pain-solution` (2 карточки) |
| C. Левая колонка + зона карточек | Слева H1 + лид + жирный вывод внизу; справа карточки | `intro` (2 нумерованные), `principle-detail` (белая + синяя) |
| D. Заголовок + сетка карточек | H1 сверху, сетка карточек под ним | `benefits-grid` (2×2 + боковая), `numbered-cards-3` (3 в ряд, тёмная) |

Правая/нижняя зона карточек внутри семейства взаимозаменяема — это и есть
точка вариативности. Калибровать шаблоны надо по семействам, а не по
придуманным именам.

шаблоны `templates/html/layouts/` подгоняются под эталоны на этапе калибровки

## Массовый импорт из Figma (2026-08-07, вторая партия)

Пользователь выложил слайды на страницу «Обложка» файла «Библиотека»
(node `855:401`). Снято **126 слайдов 1920×1080** → `canon/decks/library/`
(имя файла = `<имя фрейма>__<node-id>.png`). Каждый классифицирован по макету,
теме и качеству — полный каталог в `canon/decks/library/catalog.tsv`.

Итог по макетам: title-bullets 23, photo 17, other 17, benefits-grid 15,
cover 11, pain-solution 8, intro 8, section-divider 6, statement 5,
numbered-cards-3 5, chart 4, table 3, principle-detail 2, final 2.

Лучшие разнообразные вариации разложены в `layouts/*.var-N.png` — теперь
у всех 10 макетов от 3 до 5 эталонов (главный + вариации).

**Кандидаты в новые макеты** (при калибровке решить, какие заводить шаблоном):
- `photo-mockup` (17 слайдов) — текст/буллеты слева + крупный мокап или фото справа;
- `table` (3) — сравнительная/сеточная таблица;
- `chart` (4) — таймлайн, орг-схема, диаграмма процесса;
- `kpi` (897) — крупные цифры + фото + полоса логотипов;
- `vision-mission` (19, 69) — две крупные карточки;
- `map` (901, 28, 09) — карта с подписями/таймлайном.
