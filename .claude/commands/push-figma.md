Сгенерируй презентацию `$ARGUMENTS` в Figma по разделу 6.2 ТЗ.

Алгоритм:
1. Прочитай `input/$ARGUMENTS.md` и (если есть) собранную HTML-версию в `output/$ARGUMENTS/` — контент и выбор макетов должны совпадать.
2. Прочитай `templates/figma/FIGMA-TEMPLATES.md` и `rules/slide-layouts.md`.
3. Через Figma MCP создай новый файл (Figma Slides, если доступен, иначе дизайн-файл с фреймами 1920x1080) и наполни слайдами. Используй компоненты/стили из библиотеки пользователя, где возможно.
4. Пришли пользователю ссылку на файл и скриншоты 2-3 ключевых слайдов.
