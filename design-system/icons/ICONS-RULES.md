# Правила использования иконок

## Дополнительный набор Lucide (только недостающие пиктограммы)

- **Источник:** библиотека [Lucide](https://lucide.dev) (лицензия ISC), файлы `svg/lucide-*.svg` — **47 штук**: 2026-08-04 удалены 153 дубля фирменного набора, оставлены только пиктограммы, которых нет среди `icon-*`.
- **Стиль:** линейные (outline), скругление линий `round`, без заливки — совпадает с фирменным набором.
- **Толщина линии:** **1.5px** (приведены к фирменному штриху; исходные 2px конвертированы).
- **Цвет:** чёрный (зашит в файлы; перекрашивать под токены цвета).
- **Размеры:** базовый 24×24; масштабировать шагами (16, 24, 32, 48).
- **Каталог:** описание и «когда использовать» — в `catalog.json` (видны в приложении, раздел «Иконки»).

## Фирменный набор из Figma «Lucide icons / Tumodo (300)»

- **Источник:** Figma-файл «Библиотека» (`SZpOoVhI07GPa3Vf7BRc10`), страница/секция Icons (node `75:2`), фрейм `Lucide icons / Tumodo (300)` (node `98:2`). Импорт 2026-08-04. Файлы `svg/icon-*.svg` — 300 штук.
- **Стиль:** линейные (outline), без заливки (`fill="none"`); концы и соединения линий скруглены (`stroke-linecap="round"`, `stroke-linejoin="round"`). Факты сняты с выгруженных SVG: все 1154 контура набора идентичны по стилю.
- **Толщина линии:** **1.5px** при базовом размере 24×24 (во всех 300 файлах, без исключений).
- **Размер:** базовый 24×24 (сетка Lucide), viewBox `0 0 24 24` у всех файлов.
- **Цвет:** в файлах зашит `stroke="black"`; при использовании перекрашивать через CSS под токены `tokens/colors.json`.
- **Имена:** файлы `icon-<имя>.svg`, где `<имя>` — точное имя компонента в Figma (совпадает с именованием Lucide): от `icon-plane.svg` до `icon-ribbon.svg`.
- **Каталог:** описания всех 300 иконок — в `catalog.json` (ключи `svg/icon-*.svg`).
- **Внимание (не из Figma, вопрос пользователю):** в проекте теперь два пересекающихся набора — `lucide-*.svg` (200 шт., штрих 2px, добавлены пользователем) и `icon-*.svg` (300 шт., штрих 1.5px, из Figma). Толщина линий у наборов разная — на одном слайде их смешивать нельзя; какой набор основной, должен решить пользователь.

## Какой набор использовать (решение пользователя, 2026-08-04)

- **Основной набор — фирменный `icon-*`** (300 шт., штрих 1.5px, из Figma «Библиотека»). В презентациях используются в первую очередь они.
- `lucide-*` (47 шт., уже приведены к штриху 1.5px) — **дополнение**: используются, когда нужной пиктограммы нет среди фирменных. Дубли фирменного набора удалены 2026-08-04.
- Все иконки проекта — единый стиль: линейные, 24×24, штрих 1.5px.
