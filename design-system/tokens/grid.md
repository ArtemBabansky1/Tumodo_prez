# Сетка слайда

Формат слайда: **16:9, 1920×1080 px**.

Источник: актуальная Figma «Презентации» (`yMAUPbPKCr689lOOWHywQ8`) и подтверждение пользователя 2026-08-17. Эти значения — эталонная layout grid всех слайдов презентации; прежняя сетка 7×6 из файла «Библиотека» больше не используется.

## Параметры сетки (из Figma)

| Параметр | Значение |
|---|---|
| Размер слайда | 1920 × 1080 px |
| Поля (offset, со всех сторон) | **120 px** |
| Колонки | **7**, выравнивание STRETCH |
| Строки | **7**, выравнивание STRETCH |
| Межколонник (column gutter) | **30 px** |
| Межстрочник (row gutter) | **25 px** |
| Рабочая область (safe area) | **1680 × 840 px** (от 120,120 до 1800,960) |
| Ширина колонки | 214,286 px = (1680 − 6×30) / 7 |
| Высота строки | 98,571 px = (840 − 6×25) / 7 |
| Шаг колонки | 244,286 px (колонка + gutter) |
| Шаг строки | 123,571 px (строка + gutter) |

Фон фрейма-подложки в Figma — #FBFCFF (технический фон макета сетки; **не токен палитры**, для слайдов использовать фоны из `colors.json`).

## Правила использования

- **Ничего не выносить за пределы safe area** (120 px от каждого края), кроме фоновых заливок, фото «на вылет» и паттернов — они могут занимать весь кадр 1920×1080.
- Любой блок контента начинается и заканчивается на границах колонок/строк; дробные размеры не округлять руками — использовать CSS Grid (`1fr`).
- Типовые деления по колонкам: 7 = полная ширина; 4 + 3 (текст + визуал); 3 + 4; 2 + 2 + 3; 1 + 6 (сноска + контент). Колонки не «дробить» — контент выравнивается по их границам.
- Строки задают вертикальный ритм: заголовок обычно в строках 1–2, контент — 3–7, нижний колонтитул (номер слайда, логотип) — внутри строки 7.
- Отступы внутри блоков — по шкале `spacing.json`; между колонками ничего, кроме gutter 30 px, а между строками — gutter 25 px, не добавлять.

## Контейнеры внутри слайда (страница «Layout» файла «Библиотека»)

Три эталонных фрейма-контейнера с внутренними отступами (single-column grid = padding):

| Фрейм | Размер | Внутренний отступ | Для чего |
|---|---|---|---|
| Main frame (`222:115`) | 1684 × 840 px | **60 px** | Большой блок/карточка почти на всю рабочую область слайда |
| Medium frame (`222:117`) | 716 × 296 px | **45 px** | Средняя карточка (≈3 колонки) |
| Small frame (`222:171`) | 464 × 263 px | **35 px** | Малая карточка (≈2 колонки), плашка, бабл |

Правило: чем меньше контейнер, тем меньше внутренний отступ — 60 / 45 / 35 px. Значения продублированы в `spacing.json`.

## Другие форматы (не для слайдов, для справки)

| Формат | Размер | Поля | Колонки × строки | Gutter |
|---|---|---|---|---|
| **Layout 16:9** (слайды) | 1920 × 1080 | 120 | 7 × 7 | 30 по колонкам / 25 по строкам |
| Layout A4 (`221:161`) | 1740 × 2455 | 150 | 6 × 8 | 25 |
| Instagram post (`222:140`) | 1012 × 1350 | 76 | 5 × 5 | 25 |
| Instagram stories (`222:177`) | 1080 × 1920 | 100 по бокам, **300** сверху/снизу | 5 × 5 | 25 |

Для презентаций используется **только Layout 16:9**; остальные форматы — для печати и соцсетей.

## Реализация в CSS (для `templates/html/css/layout.css`, этап 4)

```css
.slide {
  width: 1920px;
  height: 1080px;
  padding: 120px;                              /* поля слайда */
  display: grid;
  grid-template-columns: repeat(7, 1fr);       /* 7 колонок */
  grid-template-rows: repeat(7, 1fr);          /* 7 строк */
  column-gap: 30px;                             /* межколонник */
  row-gap: 25px;                                /* межстрочник */
  box-sizing: border-box;
}
```

Фоновые элементы (заливка, паттерн, фото на вылет) выводить из потока сетки: `position: absolute; inset: 0;`.
