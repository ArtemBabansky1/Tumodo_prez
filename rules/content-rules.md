# Правила текста

> Единый свод правил по тексту слайдов: язык и тон, типографика, переносы и баланс
> строк, лимиты длин, политика переполнения. Источники — решения пользователя
> 2026-08-05 / 2026-08-07 и анализ 62 эталонных слайдов Tumodo.
> Смежные документы: `presentation-rules.md` (§4 сетка, §5 лимиты, §7 язык),
> `style-guide.md` (§2 типографика), `mistakes.md` (журнал антипаттернов).

## 1. Язык и тон

- Язык колоды = язык входного файла `input/*.md`. Смешивать языки внутри колоды нельзя.
- Тон: короткие фразы, конкретика, без канцелярита и маркетинговых клише — «Short. Clear. Zero marketing fluff.»
- Числа конкретные («500+ авиакомпаний», «USD 35M»), без округлых обещаний («значительно», «существенно»).
- Текст пользователя не сокращается и не переписывается без согласования: при нехватке места работает политика переполнения (§5), а не редактура.
- Неоднозначность в контенте — вопрос пользователю до сборки, а не догадка.

## 2. Заголовки и структура текста слайда

- H1 — без точки в конце. Абзацы и буллеты-предложения — с точкой.
- Пояснение к H1 даётся **только лидом** в двухколоночной шапке: вторые заголовки-подписи («Смысл», «Вызов») рядом с существующим H1 запрещены (решение пользователя 2026-08-05).
- Порядок текста в карточке: заголовок → абзац → список.
- **Описание из одного пункта — абзац, а не список**: точка-буллет ставится, только когда пунктов два и больше (решение пользователя 2026-08-07).
- Слайд совмещает максимум два типа контента (например, абзац + список, но не абзац + список + таблица).

## 3. Русская типографика

- Тире — длинное «—», с пробелами; дефис в составных словах не заменяется тире.
- Кавычки в RU-текстах — «ёлочки»; вложенные — „лапки“. В EN-текстах — “прямые парные”.
- Многоточие — одним знаком «…», не тремя точками.
- Знак номера «№» и единицы («₽», «%», «км») отделяются от числа неразрывным пробелом.
- Диапазоны — коротким тире без пробелов: «5–7 слайдов», «2026–2027».
- Инициалы, сокращения («т. е.», «и т. д.»), числа с единицами не разрываются переносом строки.
- **Висячие предлоги и союзы запрещены**: однобуквенные и короткие служебные слова (в, во, и, на, с, со, к, по, за, о, об, от, до, из, у, не, ни, а, но, для, при, что, как, же, ли, бы) не остаются в конце строки — уходят на следующую вместе со своим словом (в вёрстке — неразрывный пробел после них, сборщик расставляет автоматически).
- Составные слова с дефисом («тревел-услуги», «AI-аналитик») по дефису не разрываются: неразрывный дефис, слово переносится целиком.

## 4. Баланс строк и переносы

**Правило пользователя 2026-08-05, расширено 2026-08-07.** Касается **всего текста
презентации без исключения**: заголовка, слогана обложки, подзаголовка, лида, тезиса,
абзаца, пункта списка, подписи в карточке.

- Если текст не влезает в строку, на следующую переносится **сразу группа слов**, чтобы строки были соизмеримы по длине.
- Одинокое слово на последней строке запрещено; хвост из 1–2 слов при длинной первой строке — тоже.
- Ориентир при двух строках: примерно 7 слов на первой и 5 на второй.
- Примеры: «Save on your vacation with Tumodo» ломается перед `with Tumodo`, а не перед `Tumodo`; «A new feature for personal bookings — save on flights and accommodation for your own trips» — перед `and accommodation…`.
- В вёрстке: `text-wrap: balance` задан один раз на `.slide` (`templates/html/css/layout.css`) и наследуется всем текстом.
- **Единственное исключение — лид в двухколоночной шапке**: там `text-wrap: pretty`. Строки лида обязаны доходить до правого поля сетки (x=1800); `balance` укорачивает все строки и оставляет провал справа (решение пользователя 2026-08-07).

## 5. Лимиты длин и политика переполнения

Лимиты откалиброваны по EN-референсу; кириллица длиннее на ~10–20% — при RU-сборке
проверять скриншотами и при необходимости ужесточать (правку фиксировать здесь).

| Элемент | Лимит |
|---|---|
| H1 | ≤ 2 строк, ≤ 45 знаков в строке |
| Лид | ≤ 3 строк, ≤ 220 знаков |
| Пункт списка | ≤ 2 строк, ≤ 90 знаков; в списке 3–6 пунктов |
| Карточка | заголовок ≤ 2 строк + абзац ≤ 5 строк **либо** заголовок + 3–5 буллетов |
| Манифест (`statement`) | 1–2 предложения, ≤ 280 знаков |
| Подзаголовок обложки | ≤ 90 знаков |

**Переполнение решается строго в этом порядке:**

1. Разделить контент на два слайда того же макета (для серий — нумерация Pain 1…N).
2. Только для заголовка обложки: перейти с `cover-title-1` (80) на `cover-title-2` (60) — единственная разрешённая замена размера.
3. Если деление бессмысленно (неделимая таблица, цитата) — остановить сборку и спросить пользователя.

**Запрещено:** произвольно уменьшать кегль, сжимать межстрочный интервал, выходить за
сетку, урезать текст пользователя без согласования.

## 6. Мало текста (недозаполнение)

Оценка до вёрстки: строки ≈ знаки ÷ ~45 на строку колонки при `body-middle` (25/125%),
плюс зазоры списка 18px. Если текст заполняет меньше ~60% высоты контейнера —
работает §5 `presentation-rules.md` (контейнер по высоте контента, фото/мокап рядом,
шапка в левую колонку). Со стороны текста при этом действуют два правила
(решения пользователя 2026-08-07):

- **Кегль на ступень крупнее**: в слабо заполненных карточках основной текст берётся `body-big` (30) вместо `body-middle` (25).
- **Иконка к каждой карточке** из `design-system/icons/` по смыслу заголовка — она даёт вес и убирает ощущение пустоты.

Разбавлять пустоту водой в тексте («добавить пару предложений для объёма») запрещено:
пустота закрывается композицией и визуалом, а не лишними словами.

## 7. Шкала кеглей (справка)

Строго 80 / 60 / 50 / 30 / 25 / 20 / 16 (`tokens/typography.json`). Промежуточные
кегли референса (24, 31, 34, 40, 88, 90) округляются к ближайшему токену; вводить их
в вёрстку нельзя. Роли стилей — `style-guide.md` §2.

## 8. Чек-лист текста перед сдачей

Перед рендером движок обязательно запускает `scripts/lib/typograph.js`: короткие
предлоги, союзы и частицы связываются со следующим словом неразрывным пробелом.
Правило действует и для общих шаблонов, и для HTML-переопределений слайдов;
ручные переносы для исправления висячих предлогов не используются.

1. Язык колоды один и совпадает с входным файлом.
2. Заголовки без точки, предложения — с точкой; тире длинное, кавычки «ёлочки».
3. Ни одного висячего предлога/союза в конце строки.
4. Ни одного одинокого слова на последней строке многострочного текста (кроме лида в шапке — там строки доходят до правого поля).
5. Лимиты §5 не превышены; переполнения решены делением слайдов, а не кеглем.
6. Одиночное описание в карточке — без буллета.
7. Все размеры текста — из шкалы токенов.
