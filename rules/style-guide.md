# Стиль и дизайн

> Источник: визуальный анализ колод Tumodo в Figma «Презентации» (15 скриншотов-референсов всех типов макетов + структура 62 слайдов). Все цвета и стили текста — ТОЛЬКО именованные токены `design-system/tokens/`; здесь описано, **как** их применять. Иерархия источников — `presentation-rules.md` §0. Выверено советом (council-reports/).

## 1. Три темы слайдов

### Light (базовая)
- Фон слайда: `surface-gray`. Карточки: `white`, радиус 30px (из `effects.json`), без обводки, тень Shaddow-Light.
- Текст: `dark-gray-text`; второстепенный — `gray-2`; номер слайда — `gray-1`.
- H1: `dark-gray-text` (нейтральные слайды) или `blue-base` (акцентные: суть, принципы, выгоды). Внутри одного слайда H1 и лид-фразы — один и тот же акцентный цвет.
- Акценты: `blue-base` (лид-фразы, буллеты, чипы, кнопки); `peach-base` — по правилам токена (см. §3 «Бейдж боли»).

### Brand-blue (структурная)
- Фон: `blue-base` + волновой паттерн `patterns/svg/main-pattern.svg` (вертикальные скруглённые «колонны» из дуг логотипа, светлее фона, от верхней кромки вниз).
- Весь текст и логотип — `white`. Кнопки — белая обводка-пилюля.
- Используется: `cover`, `final`, `statement`, левая панель `promise`.
- Подложки на синем — `blue-pale` (по правилу токена).

### Dark (акцентная)
- Фон: `black` (#121212) — решение пользователя 2026-08-05; поверх — радиальные свечения `blue-base` или `purple-base` (одно на слайд, снизу или в центре, мягкий градиент в прозрачность).
- Карточки — «стекло» (нормировано по референсу): заливка `white` с непрозрачностью 6%, обводка 1px `white` 15%, радиус 30px, backdrop-blur 30px.
- Текст `white`; второстепенный — `white` 70%; hairline-разделители — `white` 15%.
- Чипы-пилюли — `white` с текстом `dark-gray-text`.

## 2. Типографика

Только стили из `tokens/typography.json` (Nunito Sans). Соответствие ролей:

| Роль на слайде | Токен | Параметры токена |
|---|---|---|
| Заголовок обложки/финала | `cover-title-1`, длинный → `cover-title-2` | 80/60, EB 800 |
| Слово-акцент (`promise`) | `cover-title-1` | 80, EB 800, `blue-base` |
| H1 слайда | `page-title` | 50, Bold 700 |
| Манифест, крупный тезис | `page-title` | 50 (короткий) |
| Подзаголовок-ряд («Смысл», «Вызов»), заголовок карточки, лид | `body-big` | 30, SB 600 |
| Основной текст, буллеты | `body-middle` | 25, Reg 400 |
| Ярлык колоды, номер слайда, плотные списки | `body-small` | 20, Reg 400 |
| Сноски, подписи, текст в баблах/графиках | `caption` | 16, Reg 400 |
| `library-cover-display` (144) | — | в слайдах НЕ используется |

Шкала окончательная (решение пользователя 2026-08-05): **строго 80 / 60 / 50 / 30 / 25 / 20 / 16**. Промежуточные кегли референса (24, 31, 34, 40, 88, 90) округляются к ближайшему токену; вводить их в вёрстку нельзя.

## 3. Компоненты

- **Буллет-точка**: круг 14px `blue-base` (в плотных списках 10px), по первой строке текста; отступ текста 40px.
- **Буллет-галочка**: только на карточках решений с фоном `blue-base` — белая галочка 21×18.
- **Пунктирная рельса**: точки 19px `blue-base` + вертикальная соединительная линия 3px того же цвета — для последовательностей.
- **Кружок-номер**: 43px, обводка `blue-base` 2px, цифра `body-middle` `blue-base`. Одинаков во всех темах.
- **Чип-пилюля**: радиус-пилюля, высота 58px (в потоке текста) или 100px (крупные плавающие); варианты: заливка `blue-base` + белый текст (активный/акцентный), `white` + `dark-gray-text`, `light-gray` + `dark-gray-text`, белая обводка на brand-blue. С иконкой в круге слева.
- **Бейдж боли («Pain N»)**: УДАЛЁН из макетов (правило пользователя 2026-08-05, вечер) — в шапке pain-solution не используется. Если персиковый бейдж вернётся в другом контексте: заливка `peach-base` + текст `white` (канон).
- **Кнопка**: пилюля-обводка (белая на brand-blue), текст + стрелка →, высота 78px.
- **Иконка-бейдж**: круг 58px `blue-base`, белая иконка из `design-system/icons/` (штрих 1.5px).
- **Карточка**: радиус 30px во всех темах; внутренний отступ **40px со всех сторон** (токен `card-padding`, решение пользователя 2026-08-05); порядок: заголовок → абзац → список; заполнение ≤ 80% высоты.
- **Контент светлых слайдов лежит в белых карточках**: голый текст на `surface-gray` допустим только для шапки (H1, лид) и подписей. Списки, колонки, сетки — всегда внутри белого контейнера.
- **Hairline-разделители**: 1px `light-gray` между ячейками текстовых сеток.

## 4. Декор и объём

0–2 декоративных элемента на слайд, выборочно, для объёма композиции:

- **Волновой паттерн** `patterns/svg/main-pattern.svg` — только на brand-blue слайдах.
- **Линии-росчерки** `patterns/svg/патерн-*.svg` (актуальные: патерн-1.1, патерн-2, патерн-3.1, патерн-4): на белых карточках — `surface-gray` #EEEFF2 (решение пользователя 2026-08-05), на синих — `white`; в нижней зоне карточки, всегда ПОД текстом (z-index ниже контента) (правила и зоны — `patterns/catalog.json`).
- **Бледные круги**: окружности 740–1580px, `blue-pale` (на light) / `white` с малой непрозрачностью (на brand-blue), уходят за край слайда/карточки.
- **Watermark-глифы логотипа** (сердце, петля из начертания logo): очень светлым тоном на белых карточках.
- **Рукописное обведение/подчёркивание** ключевой фразы: тонкая линия в цвет текста (белая на синем, `blue-base` на светлом); SVG, не CSS-бордер.
- **3D-объекты** из `photos/3d/`: один на слайд. Основной приём (правило пользователя 2026-08-05): если внизу слайда остаётся много пространства без контента — 3D-картинка ставится **поверх белых контейнеров** по нижней грани слайда и **уходит за неё на 20%** своей высоты (обрезается краем); не строго по центру, а со смещением влево или вправо — между карточками, для динамики (пометка [3d-pos: left|center|right], по умолчанию right). Использовать 3D на **30–40% слайдов** колоды. Вариант «3D внутри карточки» (правило пользователя 2026-08-05): картинка крупная, отступ 10px от правой границы контейнера, низ заходит за нижнюю границу контейнера на 10–15% (обрезается краем карточки), БЕЗ пересечения с текстом — текст карточки сужается (ограничение ширины строк, ранние переносы), чтобы освободить зону под 3D.

Приём «за край» — фирменный: декор и мокапы могут обрезаться краем слайда/карточки; текст — никогда.

## 5. Фото и мокапы

- Фото — только из `design-system/photos/people/` (студийные, нейтральный фон). В `split-photo` фото занимает ровно половину 960×1080, кадрирование cover; поверх — чипы.
- Текст поверх фото — только внутри чипа/бабла с непрозрачной подложкой.
- Фото на тёмных слайдах не используются (в референсе dark-слайды без фото).
- Мокапы устройств — из `design-system/mockups/files/` (macbook-pro-16-3d, macbook-на-столе, iphone_3d, карта-мира; роли — в `mockups/catalog.json`): справа или по центру, могут уходить за край; скругление врезок-скриншотов 20px.
- **Робот Theo** (`photos/3d/theo-*`) — маскот ИИ-аналитики: используется только на слайдах про ИИ/аналитику платформы; один Theo на слайд; аватарка — для баблов и чипов, ростовые версии — как 3D-акцент за краем карточки.

## 6. Do / Don't

**Do**
- Один акцент на контекст (правило токенов): на слайде один акцентный цвет.
- Слайд не должен быть полупустым: если контент занимает меньше ~60% рабочей области — добавить фото из `photos/people/` (по каталогу, под смысл слайда), иконки из `icons/` к пунктам/карточкам или декоративный элемент §4.
- Карточки одного ряда — одной высоты; сетки — по нормативам `presentation-rules.md` §4.
- Воздух: карточка заполнена ≤ 80%, между блоками ≥ 30px.
- Ключевую фразу текста выделять `blue-base` (лид-фразы в сетках выгод).

**Don't**
- Никаких цветов и кеглей вне токенов; никаких сырых HEX/px в вёрстке.
- `blue-light`, `blue-pale`, `*-soft` — не для текста (фоны/подложки).
- `black` — не фон light-темы (типографика и dark-материалы).
- `peach-base`/`green-base`/`purple-base` не сочетать с `blue-base` на одном слайде (исключение из токенов: peach-spotlight вокруг слова на синем фоне).
- Логотип не растягивать и не перекрашивать (белый/тёмный по теме — `logo/LOGO-RULES.md`, охранное поле X=60px).
- Соседние слайды не «мигают» light↔dark без смысловой причины.
- Декор не кладётся поверх текста; текст не обрезается краем.
