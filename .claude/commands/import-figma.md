Выполни шаг импорта дизайн-системы из Figma по разделу 4 ТЗ (`TZ-presentation-factory.md`) для категории и ссылки из аргументов: $ARGUMENTS

Алгоритм:
1. Зафиксируй ссылку (URL, file key, node-id, содержимое) в `figma/FIGMA-SOURCES.md`.
2. Прочитай дизайн через Figma MCP: design context, переменные (variables), при сомнениях — скриншот узла для самопроверки.
3. Запиши результат: токены — в `design-system/tokens/`, ассеты — выгрузка в соответствующие папки (вектор SVG, растр PNG 2x, имена kebab-case латиницей), правила — в соответствующий `*-RULES.md`.
4. Обнови `design-system/MANIFEST.md` и `PROGRESS.md`.
5. Покажи краткую сводку: что вытянул, что записал, что подозрительно, чего не хватает. Задай вопросы при неоднозначности.

Жёсткое правило: ничего не выдумывать — каждый цвет/размер/шрифт должен иметь источник в Figma. Нет в Figma — спросить пользователя.
