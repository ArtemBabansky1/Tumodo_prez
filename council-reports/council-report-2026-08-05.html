Совет: правила фабрики презентаций Tumodo

LLM Council · 5 советников → 5 анонимных рецензий → синтез председателя · 2026-08-05
Вопрос: по анализу 62 эталонных слайдов Figma написаны три файла правил (структура, макеты, стиль) для автосборки фирменных HTML-презентаций. Правильны ли и полны ли они? Цена ошибки высокая — правила станут законом для всех сборок.

Вердикт председателя

Где совет согласен (единогласно)

  • Черновики верно схватили визуальную систему (ритм трёх тем, лимиты текста, Do/Don't) — это сохранено.
  • Фиксировать в исходном виде нельзя: 6 кеглей вне typography.json; сетка «3×584+60 = 1812 > 1680»; самопротиворечие про манифест; бейдж боли против правила токенов; dark-тема без токенов несобираема.
  • Сильнейший анализ — Контрарианец (проверяемые, фальсифицируемые находки). Слепое пятно — у Экспансиониста (улучшения поверх невалидированного фундамента).

Где совет разошёлся

Первопринципник: «нужны слот-контракты, универсальный макет и грамматика вместо заученной дуги». Исполнитель: «вырезать всё до 7 макетов и собрать первый слайд». Решение: сделано и то и другое — слот-контракты добавлены компактно в каждый макет, несобираемое помечено [v2] с причиной, дуга переквалифицирована из закона в референс.

Слепые пятна, пойманные только рецензированием

  • Иерархия источников при конфликте (tokens → style-guide → layouts → Figma) — теперь §0 правил.
  • Политика переполнения текста (делить → cover-title-2 → спросить; никогда не ужимать кегль) — теперь §5.
  • Лимиты сняты с английских колод — калибровка под кириллицу внесена в правила и открытые вопросы.
  • Наличие файлов шрифтов Nunito Sans никто не проверял — внесено в чек-лист.

Рекомендация

Правила переписаны и записаны в rules/: каждый кегль привязан к именованному токену, сетка нормирована (540/30 · 825/30 · 390/40 = ровно 1680), «мебель» задана таблицей, добавлен универсальный макет title-bullets, 8 макетов помечено [v2]. Идеи Экспансиониста (layout-specs.json, golden-тест, diff ревизий, md-скаффолды) — бэклог этапа 4.

Один первый шаг

Положить файлы Nunito Sans (800/700/600/400) в design-system/fonts/files/ и решить открытый вопрос dark-токенов — после этого можно собирать первый слайд cover в браузере.

Полные ответы

Контрарианец — «фиксировать нельзя»
1. Типографика противоречит токенам: шкала 80/60/50/30/25/20/16, а style-guide требует 88/90/40/34/31/24 — шести размеров нет; slide-layouts (55px) спорит со style-guide (50px). 2. Арифметика сетки: 584×3+60 = 1812 > 1680 — карточки гарантированно за полями. 3. Манифест: «мебель кроме манифестов» и тут же «манифест: ярлык и номер есть». 4. Бейдж боли: colors.json — «Soft-заливка + Base-обводка, никогда наоборот», в правилах — наоборот. 5. Dark-тема без токенов объявлена рабочей. 6. Лимиты бракуют сам референс («H1 2–6 слов» против 7–8-словных эталонов).
Первопринципник — «не тот вопрос»
Правила описывают «как выглядят 62 слайда», а задача — «как детерминированно превратить произвольный markdown в колоду». Ядро — контракт «тип контента → макет → слоты с лимитами», его нет. 20 бутиковых макетов и ни одного универсала: обычный слайд из чужого markdown бездомный. Прозаические «x≈612–735» — археология Figma, не спецификация. Лучшее в черновиках: лимиты, ритм тем, Do/Don't, «делить, а не ужимать».
Экспансионист — «дожмите жилу»
1. Машиночитаемый layout-specs.json из уже собранных координат → /check-deck становится валидатором геометрии. 2. Golden-тест: пересобрать «Brand platform» фабрикой и сравнить с Figma; побочный продукт — образцовый input/brand-platform.md. 3. Diff двух ревизий — выстраданные «don't» дизайнеров. 4. Md-скаффолды контентных формул («The challenge / What it leads to / How Tumodo solves it»). 5. Реестр node-id по макетам в FIGMA-SOURCES.md; открытые вопросы снимать запросом из Figma.
Аутсайдер — «я бы собрал не то»
Ссылки на токены по именам без HEX — проверить нельзя; dark-тема обязательна, но фон «отсутствует в токенах». Термины без определения: «дуги логотипа», «росчерки», «watermark-глифы», «стеклянный бейдж», «иконка-смайл». Тильды повсюду — два исполнителя дадут разные слайды. Противоречия: манифест, позиция H1 с бейджем, 50 vs 55px, «строки или знаки». Опечатка «стат主». «Скелет адаптируется» без правил — разрешает всё.
Исполнитель — «движка нет»
templates/html/ пуст (один base.html). Блокеры: нет токена тёмного фона (3 макета); нет волнового паттерна (были несобираемы cover/final/statement — ассет добавлен в ходе сессии); кегли вне токенов; пустые mockups/ (6+ макетов); «обведение»/«стекло»/«коллажи» не делаются чистым CSS без ассетов. Для v1 — 7 макетов, остальное [v2]. Первый шаг: шрифты + dark-решение + cover в браузере.
Рецензии (5 анонимных)
Единогласно: сильнейший — C (Контрарианец); самое большое слепое пятно — A (Экспансионист): «оптимизация до валидации», «golden-тест сам бы и провалился». Упущения всего совета, найденные рецензентами: иерархия источников при конфликте; политика переполнения/деградации; калибровка лимитов под кириллицу (референс английский); наличие и лицензии шрифтов; тест лимитов фактическим рендером.
