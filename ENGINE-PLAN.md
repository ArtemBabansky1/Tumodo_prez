## Шаг 3 — контрольная сборка (вместе)

Пересобрать `theo` (или новую колоду) по новому циклу. Ты оцениваешь по шкале 1–5
каждый слайд. Всё, что ниже 5 — разбираем: причина → фикс в шаблоне/правилах →
строка в `rules/mistakes.md`.

## Шаг 4 — режим накопления (постоянно)

Дальше каждая сборка работает так: сборка → скриншоты → сверка с каноном →
`/check-deck` → показ. Каждая твоя правка обязана закончиться коммитом в движок
(шаблон/CSS/правило + строка в `mistakes.md`). Слайды, утверждённые как идеальные,
добавляются в `canon/` — эталонная база растёт, планка фиксируется.

## Критерий готовности движка

Три подряд новые презентации собраны с первого показа на 5/5 без правок по стилю
(правки по контенту не считаются).
