# Библиотека макетов слайдов

> Источник: 62 слайда колод «Brand platform & positioning» и «Tumodo at a Glance» (Figma «Презентации», `yMAUPbPKCr689lOOWHywQ8`, Section 1). У каждого макета указан референсный node-id — спорный случай решается скриншотом первоисточника. Правила выверены советом (council-reports/).

Общие условия: формат 1920×1080, поля 120px, «мебель», сетка и лимиты — по `presentation-rules.md`; темы и компоненты — по `style-guide.md`. Все текстовые стили — токены `typography.json` (в скобках указано имя токена).

В `input/*.md` макет задаётся пометкой `[layout: имя]` — она имеет приоритет. Без пометки макет выбирается по колонке «Когда». Если ни один макет не подходит — универсальный `title-bullets`; факт фиксируется в отчёте сборки.

Пометка `[v2]` = макет заблокирован: не хватает токенов или ассетов (причина указана). В сборке v1 не использовать; контент отдавать ближайшему незаблокированному макету.

## Универсальный

### `title-bullets` — заголовок + текст/буллеты
Без прямого референса — собирается из базовых компонентов. Тема light.
H1 (`page-title`). Тело — в белом контейнере (отступ 40px, радиус 30): абзацы (`body-middle`) и/или буллеты-точки в 1–2 равные колонки (gutter 25). Пометка `[image: photos/people/...]` добавляет фото справа (скругление 30, на всю высоту контейнера). Допустим лид в двухколоночной шапке.
Выбор компоновки — по политике недозаполнения (`presentation-rules.md` §5): мало текста (3–5 коротких буллетов) → обязателен сплит «карточка текста 2/3 + `photo-card` 1/3», фото подбирается по `PHOTOS-RULES.md` даже без пометки `[image:]`; в сплите список центрируется в карточке по вертикали (`justify-content: center`). Полноширинный контейнер — только когда текст заполняет его минимум на ~60% высоты. 3D поверх полупустого контейнера не ставить.
Слоты: title ≤ 2×45 зн.; лид ≤ 220 зн. (опц.); пункты 3–6 × ≤ 90 зн. или 1–3 абзаца ≤ 5 строк.
Когда: любой контент без специализированного макета. Рабочая лошадка фабрики.

## Правила выбора

1. Пометка `[layout: имя]` — приоритет.
2. Нет пометки → подбор по «Когда»; не подошло ничего → `title-bullets`.
3. `[v2]`-макет не использовать: контент — ближайшему незаблокированному, факт — в отчёт.
4. Контент не влезает → политика переполнения из `presentation-rules.md` §5 (делить, не ужимать).
5. Новый макет — только через пользователя; после одобрения добавить сюда с ref и слотами.
